# WebHire Blog & Job Listing

WebHire is a modern web application for job listings and insightful blog posts about web development, hiring trends, and the tech industry.

## Features
- Browse the latest blog posts on web development and hiring
- Explore frontend, backend, and fullstack job listings
- Clean, responsive UI

## How to Use
Open the HTML files in your browser to explore the blog and job listings.

## File Structure
- `index.html` - Home page
- `blog.html` - Blog listing page
- `blog-detail.html` - Blog post details
- `frontend.html` - Frontend jobs
- `backend.html` - Backend jobs
- `fullstack.html` - Fullstack jobs
